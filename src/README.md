# HOLLOW PINES — 夜霧の館

Raylib-cs / C# で作成した3D・FPS視点のホラーゲームのプロトタイプです。
夜の森、探索できる館、岩に囲まれた洞窟を一つのマップに配置しています。
画像・モデル・音声の別途ダウンロードは不要です。3Dモデルと効果音はコードで生成します。

## Visual Studio 2022で起動

1. Visual Studio 2022 **17.8以降**と.NET 8 SDKを用意してください。
   Visual Studio Installerの「.NET デスクトップ開発」を入れると環境を揃えやすくなります。
2. `Horror.sln` を開きます。
3. 初回はNuGetパッケージの復元を待ちます（インターネット接続が必要）。
4. `HorrorGame` をスタートアッププロジェクトにして **F5** または **Ctrl+F5**。
5. タイトルで **Enter** を押します。

Windows x64向け。OpenGL 3.3対応GPUと、Windows標準のメイリオまたは游ゴシックを使用します。
起動時のウィンドウは、マウスカーソルがあるモニターの中央に表示します。
フォントはPC上から読み込み、リポジトリには同梱していません。
ターゲットは.NET 8、Raylib-csは7.0.2で固定しています。

```powershell
dotnet build .\Horror.sln -c Release
dotnet run --project .\HorrorGame -c Release
```

## 操作

|キー|動作|
|---|---|
|W / A / S / D|移動|
|マウス|視点操作|
|左Shift|ダッシュ（スタミナ消費）|
|E|近くの鍵・鉄格子・封印・出口を調べる|
|F|懐中電灯のオン・オフ|
|Space|魔法のショットガンを発射（入手後）|
|Tab|地図を表示・非表示（時間は進みます）|
|Esc|一時停止／再開|
|Alt + Enter|全画面表示／ウィンドウ表示の切り替え|
|M|音声のミュート切り替え|
|Q|一時停止中に終了|
|R / Enter|ゲームオーバー・クリア後に最初から再挑戦|
|NEXT クリック|目撃者エンドの次のページへ（最終ページでは締めの演出へ）|
|A / 実績を見るボタン|タイトル画面でエンディング実績を表示|

画面のフォーカスが外れると自動的に一時停止します。Escで再開してください。

## エンディング実績と保存先

タイトルの「実績を見る」ボタン、またはAキーで、どのエンディングを見たか確認できます。「戻る」ボタンまたはEscでタイトルに戻ります。
現在の4種類のエンディングを記録し、まだ見ていないものは種類やタイトルを伏せて「？？？」と表示します。再挑戦やゲームの再起動後も実績は残ります。
通常のエンディングはクリア画面の表示時、「消えない目撃者」は最後の目と笑みの演出が完了した時点で記録します。

実績ファイルは `ending-achievements.json` です。保存先は起動時の作業ディレクトリに依存しません。

- **DEBUG**: `Horror.sln` と同じディレクトリの `SaveData/`。
- **非DEBUG（Release）**: 実行ファイル `.exe` と同じディレクトリ。

検証用スクリーンショットも上記保存先の `Screenshots/` に出力します。スモークテストは実際の実績データを変更しません。

Debugビルド限定で、タイトル画面の **F10** からテストプレイを開始できます。
鍵・封印の石・魔法のショットガンを取得済み、洞窟を開放済み、最初の幽霊と家族の幽霊4体を撃破済みの状態で通常の開始地点に出現します。
世界は通常の状態に戻っており、屋敷の東側には待機中の目撃者が出現しています。館の家族は残っていません。F10の処理は `#if DEBUG` で囲み、Releaseビルドでは無効です。ゲーム画面にはF10の操作案内を表示しません。

## ゲームの流れとヒント

1. 北へ進み、東側にある館の南玄関から入ります。
2. 書斎の金色の鍵をEで取得します。ここから幽霊が追跡を開始します。
3. 館を出て西へ進み、洞窟の鉄格子をEで開けます。
4. 洞窟の奥に浮く青緑色の封印の石をEで取得します。
5. 森の南端にある祭壇へ戻り、Eで封印を解けば脱出成功です。脱出可能になると祭壇と足元が明るい青緑色に大きく明滅し、木々より高い光の柱が現れます。洞窟出口からでも出口の方向を確認できます。

地図の白点は現在地、金色の点は次の目的地です。
幽霊は壁を避けて追跡します。懐中電灯を正面から当てると遅くなるので、
後退とダッシュを使い分けてください。電池は消灯中に、スタミナは走っていない間に回復します。
石の回収後は幽霊の速度が上がります。捕まるとゲームオーバーです。

## 実装

- `HorrorGame/World.cs`: マップ、円形プレイヤーの壁衝突、アイテム、進行、BFSによる幽霊の追跡。
- `HorrorGame/Game.cs`: FPS入力、3D描画、日本語HUD、地図、タイトル／ポーズ／終了画面。
- `HorrorGame/WitnessEnding.cs`: 目撃者エンドの本文3ページ、フェードと白い目の演出進行。
- `HorrorGame/EndingAchievements.cs`: エンディングの実績、JSON保存、Debug／Releaseの保存先。
- `HorrorGame/Shaders/`: 月明かり、距離フォグ、懐中電灯の円錐照明。
- `HorrorGame/Soundscape.cs`: 足音、接近時の鼓動、取得音、捕獲音の合成。
- `HorrorGame/FontLoader.cs`: WindowsのTTCフォントをメモリ上で読み込み。
- `HorrorGame/SelfTest.cs`: ネイティブ画面なしで実行できるゲームロジックの検証。

基本動作を遊べる規模のプロトタイプです。プレイ途中のセーブ、ジャンプ、複数ステージは未実装です。
隠し武器の魔法のショットガンは封印の石の取得後に出現し、近くでEを押すと拾えます。
入手後はSpaceで照準方向へ魔法の弾を発射できます。弾数制限はなく、連射には短い間隔が必要です。
弾は壁や木で止まり、幽霊に命中すると一撃で撃破します。倒した幽霊はそのプレイ中には復活しません。
幽霊を倒すと館の中に母・息子・娘・父が並び、英語の吹き出しで感謝を伝えます。
家族は各自1発で姿を消し、誰かが撃たれると残った家族のセリフが懇願に変わります（流血・損傷描写なし）。
最後の1人がいなくなると世界が不気味な暗赤色に変わり、祭壇が閉ざされます。洞窟入口の約5m手前まで通路を進むと、入る前に家族4人がマップの四隅から幽霊として同時に復活します。
家族の幽霊は通常の2.5倍の速度で追跡し、互いの斥力とランダムな横揺れによって散開します。懐中電灯を当てている間は通常時の80%の速度（20%減速）になります。母・父の2体は通常サイズ、息子・娘の2体は半分のサイズです。弾の当たり判定も体格に合わせてあり、ショットガン1発で倒せます。
4体すべて倒すと元の世界に戻り、出口が再び開きます。目撃者を生かしたまま脱出すると、一家四人惨殺の罪で逮捕・処刑される別の BAD END になります。
世界が戻った直後、屋敷の東側の外壁の陰に目撃者が現れます。黒い人間のシルエットに白い目が浮かび、最初は立ち止まってプレイヤーを見つめています。
目撃者から見える位置で7m以内まで近づくか、ショットガンを発砲すると逃走を開始します。銃声には壁越しでも反応します。ただし、ライトを消してその場で1秒以上静止してから、遮蔽物のない直撃コースへ発砲した場合、その弾には反応せず、最初の5秒間の回避も行いません。動きながらの発砲、静止時間が1秒未満の発砲、外れ弾、壁越しの発砲には従来どおり反応します。
逃走速度は8.3m/s（プレイヤーのダッシュは6.8m/s）。少しランダムに進路を変えつつ、基本的にプレイヤーから離れる道を選びます。動き出してから最初の5秒間は、至近距離のショットガンも必ず回避します。この時間は再逃走してもリセットされません。
5秒が経過して20m以上の距離を取ると、木や外壁などでプレイヤーの視線を遮れる場所を選び、隠れてじっとします。地図の金色の点で居場所を確認できます。
隠れている目撃者は、点灯したプレイヤーが見える位置の14m以内に入ると逃げ出します。消灯していても10m以内でダッシュすると足音で気づきます。ライトを消して歩けば1.5m以内に入るまで気づかないので、2〜4m程度まで静かに接近してショットガンで狙うのが攻略のコツです。銃声にも引き続き反応します。
ショットガン1発の命中で倒れ、その場に横たわります。攻撃や復活はしません。
目撃者を倒して祭壇でEを押すと、逮捕・処刑エンドに代わって **BAD END — 消えない目撃者** に進みます。
ゲーム画面が1.6秒でフェードアウトし、黒背景のエンディング専用画面に本文を3ページで表示します。右下の **NEXT** をクリックするまで各ページは表示し続けます。
最終ページのNEXTで文章が消え、暗闇に白い目が二つ浮かび上がります。目が表示された0.6秒後から、白い口が1.2秒かけて浮かび、口角を広げて不気味ににやりと笑います。目は動かずこちらを見つめ、余韻の後に口と一緒にフェードして自動的にタイトルへ戻ります。本文を読んでいる間はR・Enter・Escでは進行しません。ウィンドウが非アクティブな間は演出時間を止めます。
家族を1人以上撃ち、生存者を残して脱出するとクリア扱いになりますが、赤いクリア画面で生き残った家族による復讐の後日談が追加されます。
懐中電灯は描画上の遮蔽物による影を生成しませんが、幽霊への足止め判定には壁の遮蔽が反映されます。

## 検証コマンド

```powershell
dotnet run --project .\HorrorGame -c Release -- --self-test
# 41シーン（エンド・実績一覧の未閲覧／一部閲覧／全閲覧も含む）の描画後、自動終了
# 出力先は上述の保存先の Screenshots/（パスの指定は不要）
$env:HORROR_SCREENSHOTS = "1"
dotnet run --project .\HorrorGame -c Release -- --smoke-test
```

`--self-test`ではマップ接続と実際の衝突移動、鍵による洞窟の開閉、脱出条件、
電池・スタミナ回復、ポーズ、追跡・捕獲、ライトによる足止め、家族幽霊の同時出現・速度・斥力・撃破・世界復帰とエンディング分岐、目撃者の出現・注視・接近／銃声による逃走・障害物回避・撃破を検証します。
